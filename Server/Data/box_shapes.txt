# 종류 = Treasure(나무 상자)/Gift(선물), 상태 = Closed(닫힘)/Open(열림)/Bounds(메시 경계 상자). 직육면체 하나가 한 줄이다.
# 상자 바닥 가운데 기준 상자 좌표(cm, 나무 상자는 0.7배 적용)이고, 회전은 언리얼 회전 순서(도)다.
# 나무 상자는 몸통·뚜껑이고 열린 뚜껑은 경첩 축으로 60도 돈 모양이다. 선물은 열리면 사라져 열린 모양이 없다.
